## Результат по замечаниям

- 23 пункта, отмеченные «+», учтены как исправленные; в подробном отчёте указан способ подтверждения каждого пункта. Полная пиксельная сверка всех экранов с Figma не заявляется.
- №12: базовый размер `.sotrudnik__content` изменён на `1.25rem` (20px при базе 16px). Мобильное правило `1rem` оставлено без изменения по последней просьбе пользователя. Авторские размеры шрифтов сохраняют `rem`; сторонние библиотеки не переписывались.
- №27: табы, аккордеоны, модальные окна и метки/фильтры карты используют атрибуты поведения. Удалён селектор `.active.tab`; состояние табов и аккордеонов определяется ARIA-атрибутами. Регрессионный тест проверяет основные страницы и `dist` после удаления указанных оформительских классов. Соглашение описано в `BEHAVIOR-HOOKS.md`.
- №19, №21, №26: учтены пояснения о согласованном дизайне. Особая анимация первой студенческой ссылки и стеклянный баннер сохранены; новые требования по унификации и переключению вариантов не вводились.
- №28: HTML использует общий SVG-спрайт. Часть CSS-иконок остаётся встроенными SVG или отдельными файлами. Работоспособность проверена, но полное выполнение требования о едином спрайте для всех повторяемых иконок не заявляется.

## Последние согласованные изменения

- Мобильный баннер «Подать заявление онлайн» занимает доступную ширину; ограничение текста 265px снято.
- В карточках проектов восстановлено прежнее отображение декоративных волн.
- У `.ficher` используется `ficher-line.svg` размером 286×178px; текст при наведении расположен у верхнего отступа.
- Блок управления галереями отделён от изображения отступом 16px. Размеры точек не менялись.
- Последние ручные настройки положения/поворота волн из основных CSS перенесены в исходники до сборки. Расхождения, указанные в промежуточном отчёте для `fichers.css` и `flagship-projects.css`, устранены по основному комплекту.
