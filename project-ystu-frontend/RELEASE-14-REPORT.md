# ЯГТУ — поставка 14

Дата: 21.10.2026. Поставка содержит правки по документу «Правки к версии 13.docx» и последующие согласованные уточнения. Подробный отчёт: [V13-FIXES-2026-10-21.md](V13-FIXES-2026-10-21.md).

Обновлены адаптивные карточки и названия программ, отступы шапки и хлебных крошек, списки, таблицы, баннер подготовительных курсов, декоративная линия и фон статистики. Исправлены мобильные иконки направлений студенческой жизни, ширина и окантовка мобильного стекла. Отключено нативное перетаскивание интерактивных карточек, сохранены состояния нажатия и клавиатурного фокуса. Обводка карточек не появляется от одного hover. У кнопок структуры hover использует primary-color-2 согласно последней ручной правке пользователя. На главной подписи уровней обучения чёрные и без курсива.

Подвал сохранён, кроме отдельно разрешённого исправления размеров логотипа Redstar до 992px. Точки слайдеров не изменены.

Основные файлы, исходники и production-сборка обновлены. Production: `project-ystu-frontend/dist/` в полном архиве, `dist/` в handoff. Главная: `pages/index.html`. Содержимое dist переносится целиком с сохранением путей. Основная статическая версия используется GitHub Pages; смешивать css/ основных файлов и styles/ из dist нельзя.

Проверки: сборка 16 страниц и 1677 локальных ссылок; Chromium и Playwright WebKit на Windows для мобильного стекла, повторного клика после зажатия, контрастного декора, состояний карточек, типографики, списков и адаптивных названий. Физические Apple-устройства не проверены. Дополнительно проверяются поведенческие атрибуты компонентов, синтаксис изменённых JS и git diff --check.

Архивы: `ystu-frontend-14.zip`, `ystu-frontend-handoff-14.zip`. Упаковщик проверяет SHA256 каждого вложенного файла; контрольные суммы архивов записываются в `ystu-frontend-14-SHA256.txt`. Состав и исключения: [PACKAGING.md](PACKAGING.md).

Интеграция и реальные данные/ссылки Битрикса остаются отдельным этапом. Демонстрационная пагинация не заменяет серверную выдачу.
