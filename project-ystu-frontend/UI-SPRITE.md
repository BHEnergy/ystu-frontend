# Единый SVG-спрайт UI-иконок

HTML и авторские CSS используют один ресурс `images/svg/sprite.svg`. В него включены 35 интерфейсных иконок; 29 CSS-подключений переведены с отдельных SVG и data URI на общий ресурс.

Атлас расположен компактной сеткой. Внутри SVG используются группы `<g>`, а не вложенные `<svg>`: это исключает повреждение ресурса при внедрении скрипта перезагрузки Live Server. Проверка через canvas дополнена проверкой реального HTTP-ответа и скриншотов интерфейса.

HTML сохраняет `svg/use` с идентификатором символа. CSS использует пространственный атлас: нужная иконка выбирается через `background-size` и `background-position`. Ссылки вида `sprite.svg#...` в CSS не используются из-за ранее обнаруженной нестабильной отрисовки SVG-фрагментов. Дополнительный JS для загрузки или показа иконок не нужен.

Размеры, цвета и трансформации иконок сохранены. Декоративные линии, логотипы, фоны и уникальные иллюстрации остаются отдельными ресурсами. CSS сторонних библиотек Bootstrap/Swiper не переписываются; их внутренние изображения не относятся к авторскому набору UI.

## Поддержка

- Исходные SVG остаются в `src/images/svg/` как ресурсы для генератора; CSS на них напрямую не ссылается.
- Состав и координаты ячеек зафиксированы в `src/data/ui-sprite.json`.
- `scripts/build-ui-sprite.cjs` создаёт символы и атлас из одного набора исходников и запускается при обычной сборке.
- При изменении состава/порядка ячеек или размера атласа необходимо пересчитать CSS-координаты. Не менять manifest независимо от CSS.
- `scripts/migrate-css-sprite.cjs` — инструмент выполненной миграции, выдающий patch. Не запускать его массово для перезаписи пользовательских изменений; режим `--baseline` предназначен только для воспроизведения миграции относительно прежнего коммита.

## Проверки

- `check-css-sprite.cjs` сравнивает отрисовку 29 CSS-подключений с исходными иконками до миграции.
- `check-ui-sprite.cjs` проверяет пиксели всех 35 ячеек в основных файлах и `dist`, подключение стрелки баннера и HTML-иконки футера.
- Дополнительно проверяются табы, аккордеоны, модальные окна, карта, пагинация и адаптивные сценарии.

Это изменение выполнено после поставки 11; уже созданные ZIP-архивы не обновляются автоматически.
