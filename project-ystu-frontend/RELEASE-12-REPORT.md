# ЯГТУ — изменения поставки 12

Дата: 12.10.2026. Поставка дополняет версию 11 следующими исправлениями.

## Единый спрайт

Повторяемые UI-иконки в HTML и авторских CSS используют один `images/svg/sprite.svg`: 35 иконок, 29 CSS-подключений. HTML использует `svg/use`, CSS — координатный атлас без внешних SVG-фрагментов. Декор, логотипы и уникальные иллюстрации остаются отдельными ресурсами; стили сторонних библиотек не переписываются.

Исправлена несовместимость с Live Server: вложенные SVG в атласе заменены группами `<g>`, чтобы внедрение скрипта перезагрузки не повреждало XML. Проверены реальные HTTP-ответы и скриншоты иконок событий, хлебных крошек, аккордеонов, аккредитации и стрелок. Технические сведения — `UI-SPRITE.md`.

## Независимость пагинации от CSS-классов

Стрелки имеют отдельные атрибуты поведения `data-ui="pagination-prev"` / `"pagination-next"`. Активность панели определяется по ARIA выбранного таба и `data-tab`, не по классу `active`.

Регрессионная проверка подтверждает повторные переходы 2 → 3, обновление href стрелки, карточек, выбранного номера и URL после удаления оформительских классов. Также проверены обратная стрелка и переход по номеру без класса active у панели. Неизменённая обычная пагинация продолжает работать на 16 демонстрационных страницах; серверная выдача подключается при интеграции в Битрикс.

## Галерея подразделения

В разметке `detail-structure.html` и общего шаблона добавлен ожидаемый класс `structure-gallery__controls`. Удалены устаревшие конкурирующие правила позиционирования, новых компенсирующих правил не добавлено. Изменение также применено к UI Kit.

В основных файлах и production-сборке на 390, 768 и 1440px измерены: отступ от изображения 16px, высота управления 44px, отклонение от центра 0px. Размеры и оформление буллетов не менялись.
