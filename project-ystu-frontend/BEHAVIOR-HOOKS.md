# Селекторы поведения JavaScript

Для авторских компонентов используется единое соглашение: `data-ui` содержит разделённые пробелами роли элемента, JavaScript выбирает их через `[data-ui~="роль"]`. Существующие предметные атрибуты (`data-modal`, `data-tab`, `data-filter`, `data-campus-marker`) передают данные, а не оформление.

Примеры: `data-ui="tab"`, `data-ui="dropdown--item"`, `data-ui="button-modal"`, `data-ui="modal"`, `data-ui="campus-marker__trigger"`. Совпадение названия роли с прежним CSS-классом не связывает их: изменение `class` не требует изменения `data-ui`.

CSS-классы отвечают за внешний вид. Классы состояния (`active`, `unactive`, `open`, `modal--active`, `is-selected`) JavaScript обновляет для отображения, но в исправленных сценариях не использует их для поиска элементов и определения состояния. Табы используют `aria-pressed`, аккордеоны — `aria-expanded`, фильтры карты — внутреннее состояние и `aria-pressed`. Состояние закрытия модального окна хранится в `WeakSet`.

При создании нового аккордеона начальное состояние обязательно задаётся кнопке атрибутом `aria-expanded="true"` или `"false"`. Начальное состояние таба задаётся через `aria-pressed`. Классы оформительского состояния должны соответствовать этим значениям для корректного отображения до запуска JavaScript.

Сторонние библиотеки не переписываются: классы протокола Swiper и Bootstrap остаются частью их публичного контракта. Существующие `.js-*`-инициализаторы слайдеров являются специальными селекторами поведения, а не оформительскими классами. Данное исправление охватывает табы, аккордеоны, модальные окна и метки/фильтры карты; полная миграция всех остальных компонентов не заявляется.

Регрессионная проверка: `node scripts/check-behavior-hooks.cjs`. Она проверяет основные страницы и `dist` после удаления перечисленных оформительских классов из разметки, включая начальное раскрытие аккордеона без класса `open`.
