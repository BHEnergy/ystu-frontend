# ЯГТУ — результат повторной проверки и исправления версии 9

Дата: 08.10.2026. Основание: предоставленный документ «ЯГТУ. Повторная проверка девятой версии». Исходная версия — `d7ff6b35f6a53bd8564db37d9198f5d422affb26`. Настоящий отчёт относится к этой версии с локальными исправлениями, включёнными в новые архивы версии 9. Новый коммит и публикация в рамках этой задачи не выполнялись.

## 1. Проверка каждого нового замечания

| Пункт аудита | Проверка причины и результат |
| --- | --- |
| **1. Исправления теряются после сборки** | Подтверждено сравнением файлов: четыре исходных CSS отличались от уже исправленной основной версии. Существующие значения перенесены в `src`: позиция мобильного поиска с учётом `--header-top`, стрелки 44×44 px, открытая кнопка меню 44×44 px, мобильные инструменты 44×44 px. Основные CSS не переписывались новыми значениями. Проверено совпадение этих файлов в `src`, `dist` и `css/components`; повторная сборка побайтно воспроизводит весь `dist`. |
| **2. Поиск зависит от порядка загрузки** | Подтверждено по обработчикам: поиск привязывался только к ссылкам, существующим на момент выполнения. Позднее клонированные мобильные ссылки не получали обработчик. Добавлено делегирование клика в шапке. В Chrome и Edge, в основных файлах и `dist`, проверена задержка `header.js` на 700 мс: мобильный поиск раскрывается один раз, перехода на search.html нет, кнопка закрытия меню доступна и закрывает поиск. |
| **3. Размер точек слайдеров** | Указанное значение соответствует текущему CSS. По прямому указанию пользователя точки пагинации и их правила оформления оставлены без изменений. Этот пункт исключён из текущих исправлений; соответствие требованию 44×44 px для точек не заявляется. Размеры стрелок сохранены отдельно. |
| **4. Пагинация не меняет выдачу и не учитывает URL** | Подтверждено по прежнему скрипту: изменялось только выделение номера, page из URL не читался. На news-events добавлены две новости и два события: в каждой вкладке теперь восемь записей, шесть на первой странице и две на второй. Пагинация меняет карточки, обновляет URL и выбранный номер, учитывает прямое открытие, перезагрузку, Back/Forward и границы. При выборе темы новостей пересчитываются страницы и сбрасывается номер на первую; пустая выдача скрывает пагинацию. |

Порядок инициализации фильтров тем и пагинации согласован, чтобы первоначальный выбор темы не сбрасывал номер из URL. Существующие карточки первой страницы сохранены. Дополнительные записи — демонстрационные; названия и даты не объявляются утверждённым контентом университета.

## 4. Выполненные проверки

Среда: Windows, Google Chrome **154.0.8037.98**, Microsoft Edge **154.0.4258.62**, автоматизация через Playwright. Основные файлы и dist проверялись отдельно.

- `check-v9.cjs`: совпадение исправленных CSS, сохранность правил точек, побайтная воспроизводимость повторной сборки; поиск при задержке шапки; пагинация новостей и событий, URL, перезагрузка, история, Enter, фильтры и граничное состояние. Эти сценарии проверены в Chrome и Edge на 390×844.
- `check-client-fixes.cjs`: формы, маска телефона, выбор файла, фильтры, CMS-контент, адаптивные изображения и поиск — основной комплект и dist в Chrome.
- `test:ui:legacy` и `test:ui`: 15 основных страниц в каждом из двух комплектов на ширинах 390 и 1440 px; отсутствие горизонтального переполнения и alt-заглушек, взаимодействия каталогов, вкладок, тем, аккордеонов и слайдеров, пагинация, низкое меню и состояния кнопок. Диагностическая map-test включена в сборку и проверку ссылок, но не в этот браузерный прогон.
- Проверка сборки: 16 страниц, 1362 локальные ссылки; проверка синтаксиса изменённых JS и `git diff --check`.

Полная матрица всех последних двух версий браузеров, физические мобильные устройства и повторная сверка Figma до 2–3 px не проверялись. Показатели скорости и Lighthouse из входного аудита относятся к прежнему прогону; они не выдаются за измерения исправленного комплекта.

## 5. Передача

Актуальный статический production frontend находится в `project-ystu-frontend/dist`; главная — `dist/pages/index.html`. Основные pages/CSS/JS и компонентные исходники синхронизированы.

- `ystu-frontend-9.zip` — полный комплект по структуре предыдущего полного архива.
- `ystu-frontend-handoff-9.zip` — исходники, dist, скрипты сборки и документация по структуре предыдущего handoff.

Оба архива включают настоящий отчёт, актуальный чек-лист и инструкции. Прежние архивы версии 9 сохраняются под резервными именами. Контрольные суммы новых архивов поставляются рядом. node_modules, Git-история, docs, .vscode, .codex и результаты служебных тестов в архивы не включаются.

Демонстрационная пагинация готова для проверки статического интерфейса. На Битриксе необходимо связать её с реальными данными, количеством записей, URL и сохранением условий; клиентские демонстрационные обработчики адаптировать к выбранному серверному компоненту.

Итог: подтверждённые ошибки сборки, инициализации поиска и демонстрационной пагинации устранены. Оставленные по указанию пользователя точки и отдельно перечисленные рекомендации не скрыты и не объявляются закрытыми.
