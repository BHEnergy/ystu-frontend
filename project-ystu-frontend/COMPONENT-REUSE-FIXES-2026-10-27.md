# Результат доработки переиспользования компонентов

Дата: 27.10.2026. Основные файлы, src и dist обновлены. Коммит, публикация и архивы не выполнялись.

## Согласованные исключения

- Порядковый декор Полезных ссылок сохранён как задуманное поведение.
- Дублирующиеся шаблоны направлений и карточек программ не объединялись. Для event-modal добавлены только необязательные параметры экземпляра, необходимые для уникальности ID.
- Подвал не менялся.

## Исправлено

1. Правила program-exams__description перенесены из program-about.css в собственный CSS компонента.
2. Направления получили адаптацию к ширине контейнера, min-width:0 и локальную мобильную компоновку управления галереей. Проверена вставка в контейнеры 280/400/700px при окне 1920px, без горизонтального переполнения.
3. Полезные ссылки получили собственное display:grid и сетку, адаптирующуюся контейнерными запросами; внешние d-grid/grid-list-3 больше не обязательны для базовой раскладки. Количество колонок на узких контейнерах — 1/1/2 для 280/400/700px.
4. Намеренное оформление чёрных плашек на главной перенесено с селектора родителя university-statistics на модификатор structure__program--plain.
5. Добавлены SiteUI.ready и async SiteUI.init(scope), а также Galleries.init(scope). Инициализация галерей ограничена переданным контейнером, существующие Swiper повторно не создаются. Двойное подключение main.js защищено.
6. Tabs, CatalogSearch, FilterPanel и Validation получили идемпотентный init(scope). Панели фильтров ищут свои кнопки локально; поиск читает актуальные карточки. Проверка новых модальных форм подключается общим SiteUI.init.
7. Пагинация получила init(scope), обновление карточек, независимые ключи URL и возможность отключить запись URL. Старый одиночный листинг сохраняет page/tab. История браузера и два экземпляра проверяются отдельно.
8. Модалки получили init(scope), делегированные новые триггеры, явный target и локальную область. Добавлены необязательные eventModalId/eventModalKey/modalIdPrefix с прежними значениями по умолчанию. Исправлено пересечение закрытия и открытия разных окон.
