## JavaScript и экземпляры

- dropdown.js:1–8,88–91 — уже есть Dropdown.init(scope), локальный поиск и WeakSet. Это подходящий образец для других компонентов.
- js/main.js:166–242 — несколько исходных галерей используют собственные элементы управления. Но initSwiper закрыт внутри IIFE (:21) и вызывается при запуске (:290); публичной точки инициализации добавленной галереи нет.
- tabs.js:130–147, catalog-search.js:2, pagination.js:4 — инициализация только при загрузке, без публичного init(scope).
- pagination.js:3,14,20–24 — выдачи используют общие параметры URL page/tab. Карточки разделены локально, но независимым листингам нужны разные ключи восстановления состояния. Это ограничение нескольких экземпляров, не поломка обычной пагинации.
- modals.js:95–103 — динамически добавленные триггеры не получают обработчик; одинаковый data-modal выбирает первое окно. event-modal.njk:6,31–39 содержит фиксированные ID, поэтому повторное включение создаёт дубликаты. В vacancy-modal.njk уже есть префикс — его подход можно переиспользовать.

## Что не требует переписывания

Само наличие student/program в БЭМ-имени не доказывает зависимость от страницы. Три названных блока уже не требуют родительского элемента исходной страницы. student-links и program-exams используются общими include; student-gallery-detailed.njk делегирует student-gallery.njk. Существующие галереи поддерживают несколько первоначальных экземпляров. Эти решения следует сохранить.

## Предлагаемая карта

- Общая сетка карточек + карточка ссылки; совместимые существующие БЭМ-классы и явные варианты декора.
- Секция «текст/иконка/галерея» с модификатором reverse и параметризованным шаблоном.
- Сетка показателей + общий disclosure, без привязки к экзаменационному содержимому.
- Один program-card с параметрами данных и подписей.
- Единый идемпотентный init(scope), локальные элементы управления, идентификаторы экземпляров и собственные ключи URL там, где они нужны.
