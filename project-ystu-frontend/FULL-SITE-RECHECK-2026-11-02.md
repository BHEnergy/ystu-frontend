### Проверенное поведение

- Шапка: открытие/закрытие меню, поиск, Escape, снятие блокировки прокрутки; низкое окно и достижимость ссылок.
- Каталоги: поиск, пустая выдача, восстановление карточек, фильтры и возврат фокуса.
- Новости: переключение выдачи, URL, последовательный проход всех 16 демонстрационных страниц.
- Структура: переключатели, ARIA и пустые категории.
- Аккордеоны: клавиатура, изменение состояния, анимация закрытия и reduced motion.
- Слайдеры главной, студенческой жизни, подразделения и UI-Kit: инициализация и стрелки; независимость экземпляров и варианты fraction/bullets.
- Карта: статические метки, popup, Escape и фильтр.
- Поиск по сайту: отправка запроса и демонстрационная выдача.
- Модальная форма: открытие, фокус, телефон, файл, Escape и возврат фокуса. Отправка на реальный сервер не проверялась.
- Карточки: отсутствие нативного drag-залипания, следующий клик и контраст фокуса.

### Флаги сканера обрезания

В 112 сочетаниях сканер отметил увеличенную scroll-область фичеров/проектов с `overflow: hidden`. Флаги относятся только к этим двум типам карточек. Дополнительная проверка реальных текстовых прямоугольников в 120 сочетаниях не обнаружила выхода текста за границы карточек. Намеренное обрезание декоративных волн не засчитывалось как потеря содержимого.

## Исключения и оставшиеся вопросы

1. В основной версии на локальном адресе внешний API Яндекс Карт заблокирован: Chrome сообщает ORB, WebKit — HTTP 403. Неуспешных локальных ресурсов нет; проверки статической карты прошли. Причина ограничений внешнего API этим прогоном не установлена, работу интерактивного API на домене клиента нужно проверять отдельно.
2. Прежний нестабильный сбой поиска на WebKit/touch в текущих сценариях не воспроизведён. Реальные iPhone/iPad не проверялись; объявлять аппаратный риск устранённым нельзя.
3. Попиксельная сверка с Figma и согласование геометрии волн не выполнялись. Существующее решение по адаптивной сетке не менялось.
4. Проверка H1 не заменяет полный аудит иерархии заголовков. Остальные предупреждения о section/article и заголовках из менеджерского аудита этим прогоном не закрывались; новый прогон Nu Validator не выполнялся.
5. Не проверялись Bitrix, серверные фильтры/поиск, реальная отправка форм, сервер клиента, старые ZIP, Firefox, Яндекс Браузер и физический стилус. Playwright WebKit не равен Safari на устройстве.
6. Подвал и дизайн bullets не изменялись.
