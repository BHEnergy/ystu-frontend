# Проверка состояний интерактивных элементов

Дата: 06.11.2026. Основание — замечание о недостающих состояниях кнопок и ссылок на всех страницах. Ориентир — ручная правка hover тегов новостей и существующая палитра компонентов. Новая сверка с конкретным фреймом Figma не заявляется: node-id не предоставлен.

Проверены 15 основных HTML-страниц, UI-kit среди них; production содержит 16 страниц, включая техническую map-test. Состав ссылок и кнопок можно повторно получить через `node scripts/audit-interactive-elements.cjs`.

## Исправлено

- Новости/события: сохранён пользовательский фон hover тегов; правка перенесена в src/dist. Добавлено нажатие и отклик выбранных тегов, заголовков-переключателей. Hover ограничен мышью. Эффект карточки новости работает при наведении на всю ссылку, а не только фотографию.
- Каталоги программ и вакансий: состояния сброса фильтров, открытия панели, кнопки поиска, закрытия мобильной панели и её раскрывающихся секций.
- Шапка и поиск: фон интерактивных иконок, отклик логотипа-ссылки и кнопки закрытия поиска.
- Программа, студенческая жизнь, сотрудник и подразделение: текстовые контакты/ссылки, «Подробнее», раскрытие примеров экзаменационных работ, видео-ссылка подразделения; нажатие табов и hover уже выбранного таба.
- Карта: кнопка поиска, заголовки фильтров, нажатие пунктов и маркера, кнопка закрытия popup. Открытие popup и фильтра не заменяет видимое состояние самой кнопки.
- Слайдеры и баннеры: отклик стрелок, точек и баннеров без изменения transform/координат управляющих элементов. Disabled/заблокированные стрелки исключены.
- Формы: отклик «Прикрепить файл» и возврата после успешной отправки. Существующий фокус выбора файла через focus-within сохранён. Добавлен отклик ссылок согласия и cookie.
- UI-kit: состояния общих компонентов обновлены автоматически; добавлен отклик ссылок оглавления и вводных блоков.
- Disabled-состояния общих кнопок и пагинации не реагируют как доступные элементы.
- Summary включён в общий видимый клавиатурный фокус. Для добавленных переходов предусмотрен prefers-reduced-motion.

Неинтерактивные span/p с плашками уровня обучения, формы обучения и статистики не превращались в кнопки. У уже работающих кнопок, документов, карточек и ссылок сохранены их компонентные состояния.

## Ограничение подвала

Подвал оставлен без изменений по AGENTS.md: разрешение от 23.10 касается конкретных замечаний о компоновке, но не распространяется на новый пересмотр интерактивных состояний. CSS подвала в основных файлах, src и dist автоматически сравнивается с HEAD.

## Проверки

- `npm test`: сборка 16 страниц, 1757 локальных ссылок.
- `node scripts/check-interaction-states.cjs`: 44 группы элементов, 612 проверок hover/active/focus-visible для основных страниц и ещё 612 для dist. Chromium действительно рассчитывает принудительные псевдосостояния через CDP; сравниваются цвета, фон, границы, тени, декор, outline, filter и transform. Это проверка CSS-состояний, не утверждение о полной проверке пользовательских сценариев.
- Отдельно — сенсорный контекст Chromium 390 px: отсутствие залипающего hover у проверяемых кнопок, сохранение active/focus. Reduced motion проверяется в UI-kit без тестового принудительного отключения переходов. Повторный запуск только этих проверок: `node scripts/check-interaction-states.cjs --media-only`.
- Проверки синтаксиса новых JS-скриптов и `git diff --check`.

Уточнение пользователя: у «Очистить» на hover/active меняется только цвет текста, фон остаётся прозрачным. Hover логотипа убран, клавиатурный фокус сохранён. Для баннеров затемнение заменено мягкой внешней тенью на hover и внутренней тенью на нажатие.

Основные CSS, соответствующие src и dist обновлены. HTML-структура и JavaScript сайта не менялись. Коммит, push и обновление архивов не выполнялись.
